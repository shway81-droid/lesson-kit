# textbook — 교과서 원본 보관

학기별로 폴더를 두고 그 학기 교과서 PDF 와 진도표를 함께 넣는다.

```
textbook/
  5-2/
    초_사회5-2(박기범)_교과서.pdf              182쪽, 텍스트 레이어 있음
    초_사회5-2(박기범)_나이스업로드용진도표.xlsx   48행 (합치면 43차시)
```

**이 폴더는 깃에 올리지 않는다.** 출판사 저작물이라 `.gitignore` 에서 `textbook/` 을 통째로
제외한다. PDF 뿐 아니라 진도표 xlsx 도 마찬가지다. 새 학기 폴더를 만들어도 따로 손댈 것은 없다.

## 쓰는 법

차시 목록과 쪽 범위를 진도표에서 뽑는다.

```bash
PYTHONUTF8=1 python scripts/read_progress_plan.py \
  "textbook/5-2/초_사회5-2(박기범)_나이스업로드용진도표.xlsx" \
  --unit 1 --verify "textbook/5-2/초_사회5-2(박기범)_교과서.pdf"
```

출력의 `--from-page` / `--to-page` 를 그대로 `split_lesson.py` 에 넘긴다.

## 학기별로 확인할 것

교과서 쪽 번호와 PDF 안 순번의 차이(`--offset`)는 책마다 다르다. 앞표지·차례 장수가 다르기
때문이다. 새 교과서를 넣으면 `--verify` 로 차시 첫 쪽의 앞머리를 찍어 제목과 맞는지
반드시 눈으로 확인한다.

| 학기 | 교과서 | offset | 확인일 |
|---|---|---|---|
| 5-2 | 천재교과서 박기범 | 1 | 2026-09-04 |
